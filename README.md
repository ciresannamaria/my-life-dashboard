# My Life Dashboard

A personal life management dashboard.

## Current prototype

- Coffee-inspired responsive design with mobile bottom navigation and desktop sidebar.
- Overview shows today's date in DD.MM.YYYY format, the ISO week number, and a countdown to the next holidays.
- Other navigation pages are intentionally blank except for their page heading while we plan them together.
- Placeholder text and sample dashboard cards have been removed.

The holiday countdown is currently set to **12.12.2026** and counts calendar days, including weekends.

## Publish with GitHub Pages

1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then save.
5. Wait for GitHub Pages to finish publishing.

On mobile, open the website and use the browser menu to choose **Add to Home screen** or **Install app**.

## Privacy

The repository and prototype website are public and do not yet have login protection. Do not enter personal information or add secrets. We will connect Supabase authentication and row-level security before storing private records.
